# goit-rdb-hw-02

ДЗ з курсу РБД. Нормалізація таблиці до 3НФ, ER діаграма та створення таблиць у MySQL.

## Структура репозиторію

| Файл | Опис |
|---|---|
| normalized_table.xlsx | Таблиці на кожному етапі нормалізації (1НФ, 2НФ, 3НФ) |
| Create_Tables.sql | Створення БД hw02 і таблиць clients, orders, order_details |
| Insert_Values.sql | Заповнення таблиць даними |
| Select.sql | Перевірочний запит SELECT до таблиці clients |
| screenshots | Скріншоти до кожного пункту завдання |

## Етапи Нормалізації

1. 1НФ (p1_1nf.png). Товари в однієї комірки було рознесено по окремих рядках. Усі значення атомарні.
2. 2НФ (p2_2nf.png). Часткові залежності усунуто. Дані було розділено на Замовлення та Деталі замовлення.
3. 3НФ (p3_3nf.png). Транзитивну залежність order_id -> клієнт -> адреса усунуто, а клієнтів винесено в окрему таблицю.

## ER Діаграма

![ER Діаграма](screenshots/p4_diagram.png)

Як можемо бачити з даної діаграми, clients 1 : N orders - клієнт може мати багато замовлень та orders 1 : N order_details - замовлення містить один або більше товарів.

## Запуск

Запустити скрипти в MySQL у такому порядку:
1. `Create_Tables.sql`
2. `Insert_Values.sql`
